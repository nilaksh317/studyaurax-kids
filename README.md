# StudyAuraX Kids — Colour the Real World

A free static colouring website with 26 interactive pages.

## Publish using GitHub Pages

1. Create a new **public** GitHub repository (for example, `studyaurax-kids`).
2. Upload **index.html** from this folder to the repository root and commit it.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, and save.
5. Wait for GitHub Pages to publish, then open the URL shown under Pages.
6. Test a colouring page, Undo/Redo, Restart, brush/eraser, save picture, and reload progress on phone and desktop.

No paid hosting, API keys, or build tools are required. Local progress is stored in each browser/device; it does not sync across devices. External song links open YouTube search and should be used with parent supervision.
